# Day 04

## 受講者が実装する場所

- `day04/app.py` の `run_chain()`

## 目的

- LangChainで処理を部品化してつなげる
- Tool callingの最小構成を作り、ツールの引数検証/制限を理解する

## ゴール（完了条件）

- LLMからツールが1回以上呼び出される
- 不正引数でツールが実行されない

## ツール仕様

- ツール名：`add`
- 入力：`a`（整数）, `b`（整数）
- 出力：`a + b`（整数）
- 許可リスト/制限：`add` のみ実行可。整数のみ許可（文字列・小数・bool は不可）、絶対値は10^12まで

例（どれか1つでOK）

- 日付取得ツール（`today`）
- 簡易計算ツール（`add`/`multiply`）
- 固定データ検索（`lookup_company_policy` など、ローカル辞書から検索）

本研修テンプレでは、未経験者が迷わないよう、以下のいずれか1つを必須ツールとして実装してください。

- ツール名：`today`
  - 入力：なし
  - 出力：`YYYY-MM-DD`（文字列）

または

- ツール名：`add`
  - 入力：`a`（整数）, `b`（整数）
  - 出力：`a + b`（整数）

## 機能要件

コマンド

- `python -m day04.app` で起動できること（モジュール名は固定）

必須オプション

- `--text`：ユーザー入力（文字列、必須）

出力

- 標準出力に最終回答（文章）を出力する

終了コード

- 正常終了：`0`
- 入力不備：`2`
- 実行失敗（LLM/ツール呼び出し失敗等）：`1`

必須要件

- 上記の必須ツール（`today` または `add`）を実装し、LLMから1回以上呼び出す
- ツール引数を検証する（`add`の場合は整数のみ許可、など）
- ツール呼び出しに失敗した場合に、安全に失敗する（終了コード `1` でよい）

受け入れ基準

- ツールが呼び出されたことがログで分かる
- 不正な引数でツールが実行されない

## 実装タスク

- `day04/app.py` の `run_chain()` を実装し、機能要件を満たす
- ツール（`today` または `add`）を実装し、ログで呼び出しが分かるようにする

## 実行方法

### 実行コマンド例

```bash
# todayツールを使う例
python -m day04.app --text "今日の日付を教えて"

# addツールを使う例
python -m day04.app --text "123と456を足した結果を教えて"
```

### 期待する出力例

```
# todayツールの場合
今日は2024-12-01です。

# addツールの場合
123と456を足すと579になります。
```

## セルフレビュー

- 正常系：ツールが1回以上呼ばれ、回答に反映される
  - `--text "123と456を足した結果を教えて"` → ログに `TOOL CALLED: add(a=123, b=456)` が出て、回答「579です」、exit=0
- 異常系：ツール引数が不正な場合に安全に失敗する
  - 文字列・小数・bool・引数不足・上限超え・許可外ツールの6件で `TOOL REJECTED` となり、ツールは実行されない
  - `--text "10000000000000と1を足して"` → LLMは `add` を要求したが検証で弾かれ、exit=1
  - `--text ""` → exit=2
- 境界：入力が長くてもツール呼び出しが破綻しない
  - 1500文字＋計算依頼 → ツールが正しく呼ばれ「42」、exit=0
  - 2001文字以上 → Bedrockを呼ぶ前にエラー、exit=1
- 再実行：同じ入力で複数回実行してもクラッシュしない
  - 同じ入力で3回実行し、3回とも同じ回答・exit=0

## リサーチメモ（任意）

調べたURLや、理解した要点をメモしてください。

- LangChainの基本（チェーン/Composableな実行）
  - `prompt | llm` のように `|` で部品をつなぐと、左の出力が右の入力になる
- Toolの設計（入力、出力、失敗時の扱い）
  - `@tool` を付けると、関数名・docstring・型ヒントがLLMへの説明になる
  - 引数が不正なら例外を投げて実行せず、終了コード1で終わる
- 許可リスト（想定外のツール実行を防ぐ）
  - `ALLOWED_TOOLS = {"add"}` にないツール名は実行しない
